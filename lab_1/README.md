# Overview

- `./docs` contains all relevant documentation for this lab:
   - [README.md](./docs/README.md): This file contains the lab specifications and manual tests for verifying that the specifications have been met.
   - [report.md](./docs/report.md): This empty document is where you should write your lab report.

- `./code` contains a basic shell skeleton in [lsh.c](./code/lsh.c).
   Your task is to build on it to meet the lab specifications.

- `./tests` contains a set of automated tests and instructions for running them.
   These automated tests complement the set of manual tests found in [README.md](./docs/README.md).
