# Overview

- [./docs/README.md](./docs/README.md) contains the functional specifications and manual checks.

- `./code` contains a basic shell skeleton in [lsh.c](./code/lsh.c).
   Your task is to build on it to meet the lab specifications.

- `./tests` contains local automated tests and instructions for running them.
   These tests complement the manual checks in [README.md](./docs/README.md).
