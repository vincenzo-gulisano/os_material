### Introduction

- This assignment will give you a deeper understanding of the implementation of synchronization in an operating system. In this lab, your task is to extend the functionality of Pintos and improve the performance of the `timer_sleep()` function. Although Pintos already provides a working implementation, it uses busy waiting, which means that it spins in a loop, checking the current time until enough time has passed. Reimplement this function to avoid busy waiting.
